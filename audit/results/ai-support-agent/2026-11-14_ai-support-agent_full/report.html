SEC-001Missing Brute-Force Rate Limiting on Admin Login Endpoint
HHighU0 NowSecurityai-support-agentconfirmedEffort S (~4h)Fix risk lowfixed#1
Evidence

POST /api/admin/auth/login directly calls authenticateUser(email, password) without checking IP attempt counters or account lockout thresholds.

src/app/api/admin/auth/login/route.ts:35-48

Fix

Implement sliding-window IP and account rate limiting (5 failed attempts per 15 minutes) before invoking scrypt password verification.

Proof test: Automated script sending 10 consecutive failed login requests receives HTTP 429 Too Many Requests.

Why it matters

Attackers can perform automated dictionary attacks against administrator accounts, potentially gaining full control of the platform.

Root cause

Authentication handler lacks request throttling and lockout middleware.

Urgency: Publicly accessible authentication endpoint with scrypt password verification vulnerable to automated credential stuffing.Chain: CHAIN-1Wave: wave-0

MMediumU1 This sprintSecurityai-support-agentconfirmedEffort S (~2h)Fix risk lowfixed#2
Evidence

src/middleware.ts checks only Boolean(req.cookies.get(SESSION_COOKIE_NAME)?.value) without verifying the HMAC signature.

Strengths to keep

Robust Multi-Tenant Cryptographic Isolation

Tenant secrets (OpenAI API keys, database URLs, SMTP credentials) are encrypted at rest with AES-256-GCM using a 32-byte master key. Credentials are only decrypted into memory when executing tenant-scoped requests and never leaked to the client.

src/lib/security/encryption.ts:18-50

Graceful Database Connectivity Fallback

When customer MongoDB Atlas clusters are unreachable or reject connections, call records automatically fall back to the platform database to guarantee zero lead loss.

src/lib/db/conversation-store.ts:60-85

Proactive Autoplay Policy Recovery

Client audio player primes browser media activation upon widget interaction and stashes audio on direct load, eliminating playback deadlocks.

src/hooks/use-audio-player.ts:160-195

Zero-Error TypeScript & ESLint Baseline

Entire codebase compiles under strict TypeScript with 0 compiler errors and 0 lint warnings.

  • HHigh Likely significant incident or a broken core guarantee, with some precondition.
  • MMedium Real weakness with limited reach or unusual conditions.
  • LLow Hardening, polish or small maintainability issue.

Sequence is the recommended order to fix things. It follows urgency first, then dependencies (blocked-by), then quick wins, and puts risky changes last. It is a recommendation, not an instruction.

Confidence: confirmed (traced or reproduced) · likely (strong evidence, not fully traced) · suspected (worth a human look).

Quick win: high impact, small effort, low fix risk.
